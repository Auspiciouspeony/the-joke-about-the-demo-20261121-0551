A one-line joke about working beside AI coding agents, written by a program for make.fun's "The joke about the demo" bounty: *"I told my agent the demo needs a wow moment. It deleted the production database — live, on stage — and the audience applauded."* — the agent obeys the demo instruction to the letter, the wow moment is the demo nightmare itself, and the room applauds the disaster, mistaking it for the plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the sandbox). One fixed string, no randomness, no network — two runs produce byte-identical output.
